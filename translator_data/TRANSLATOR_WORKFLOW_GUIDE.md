# Translator Workflow Guide
## Professional Translation Project Management

**For: Project Manager**  
**Purpose:** Manage professional translators and ensure quality translations  
**Version 1.0 | August 2026**

---

## 1. Translator Selection Criteria

### Required Qualifications
- ✓ **Native speaker** of target language
- ✓ **Professional experience** (3+ years translation)
- ✓ **Real estate OR tech domain** experience preferred
- ✓ **Portfolio samples** available for review
- ✓ **References** from previous clients
- ✓ **Responsiveness** (timely communication)
- ✓ **Attention to detail** (quality-focused)

### Preferred Qualifications
- Localization experience (UI/app translation)
- CAT tool experience (SDL Trados, MemoQ, etc.)
- Familiarity with Uzbekistan/Central Asia
- Previous real estate translation work

### Disqualifying Factors
- ✗ Relies solely on machine translation
- ✗ No verifiable portfolio
- ✗ Slow turnaround history
- ✗ Quality complaints from references
- ✗ Non-native speakers

## 2. Translator Contact Strategy

### Sources for Finding Translators

**Option A: Freelance Platforms**
- Upwork
- Fiverr
- Guru
- PeoplePerHour

**Option B: Professional Networks**
- Local translator associations
- University translation programs
- Translation agencies
- LinkedIn professionals

**Option C: Referrals**
- Ask existing translators for recommendations
- Contact previous clients' translators
- Professional communities

### Screening Process

**Step 1: Initial Inquiry (Email)**
- Provide project overview
- Share language-specific requirements
- Request portfolio + references
- Mention budget ($300-350 per language)
- Set response deadline (2-3 days)

**Step 2: Portfolio Review**
- Verify sample quality
- Check domain experience
- Review terminology handling
- Assess writing style

**Step 3: Reference Verification**
- Contact 1-2 references
- Ask about: quality, punctuality, responsiveness
- Confirm similar project experience

**Step 4: Confirmation Call (Optional)**
- Discuss project details
- Clarify expectations
- Test communication style
- Answer translator questions

**Step 5: Contract & Payment Setup**
- Send translator contract
- Clarify payment terms (50/50 split)
- Set deadline and milestones
- Confirm file delivery method

## 6. Quality Assurance Checklist

When translator submits completed CSV:

**Completeness:**
- [ ] All 165+ rows have translations
- [ ] No empty cells in translation column
- [ ] File naming correct (translations_[LANG].csv)
- [ ] UTF-8 encoding

**Technical:**
- [ ] All variables ({{...}}) preserved exactly
- [ ] No HTML entities or smart quotes
- [ ] Proper punctuation and capitalization
- [ ] No hardcoded English mistakes

**Quality:**
- [ ] Terminology consistent throughout
- [ ] No typos or grammar errors
- [ ] Appropriate formality level maintained
- [ ] Natural phrasing (not word-for-word)
- [ ] Real estate terminology correct

**Submission:**
- [ ] Notes on tricky translations (if any)
- [ ] Confidence statement from translator
- [ ] Confirmation email sent

## 7. Communication Protocol

### Response Time Expectations
- Translator to PM: Within 1 business day
- PM to Translator: Within 1 business day
- Revision feedback: Within 2 days of submission
- Final approval: Within 2 days of revision

### Escalation Process
If translator misses deadline by 2+ days:
1. **Day 1:** Friendly check-in email ("Just checking in...")
2. **Day 2:** More direct email ("Need update on timeline...")
3. **Day 3:** Consider backup translator if no response

If translator submits low-quality work:
1. **First:** Detailed feedback with specific revisions
2. **Second:** Video call to discuss, if needed
3. **Third:** Consider replacing translator
